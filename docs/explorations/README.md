# Explorations

Design notes for ideas that are not built yet: what each would look like,
what hedgesync already has for it, the open questions, and a suggested
first step with a rough estimate.

| Note | In one line | First step |
|---|---|---|
| [Live sections](live-sections.md) | blocks a program keeps current; two-way as a control panel | ~1 day |
| [Runnable code blocks](runnable-blocks.md) | code fences that run, output below; trusted authors, sandboxed | ~2 days |
| [Change log](change-log.md) | every change with time and author, in SQLite (evaluation) | 2–3 days |
| [Chat bridge](chat-bridge.md) | a chat room and a note section mirror each other | 2–3 days |
| [Live transcript](live-transcript.md) | speech transcribed into a note while people edit it | ~1 day |
| [Incident war room](incident-room.md) | alerts, people and commands on one timeline; ends as a postmortem | ~1.5 days |
| [Task sync](task-sync.md) | checkboxes ↔ GitHub issues, Taskwarrior, CalDAV todos | ~2 days |
| [Mirror with a filter](filtered-mirror.md) | a live copy without secret parts (GM notes → player handout) | ~1 day |
| [Spreadsheet tables](table-formulas.md) | computed cells in Markdown tables | ~1.5 days |
| [Share a project](project-share.md) | Live Share for a directory, files as notes, follow across files | ~3 days |
| [Commit messages together](commit-messages.md) | `git commit` opens a shared note | ~0.5 day |
| [Code review in a note](review-in-a-note.md) | a PR's diff as a note, comments posted back as a review | ~2 days |
| [Clipboard](clipboard.md) | a private note as a clipboard across devices | ~1 day |
